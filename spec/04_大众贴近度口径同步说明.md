# 每日要闻 · 大众贴近度口径同步说明

## 现行口径（四处一致）

目标读者是普通大众，只收大多数人会关注、与日常生活和切身利益贴近的资讯。

- **大众贴近度正面清单**：衣食住行与物价消费、工作与就业、医保与社保、工厂与制造业、制药业与医药、AI 发展、新能源、地方政府负债与化债、房地产、企业倒闭与资不抵债、社会议题；重大天气预警、全国性公共安全事件、现象级文娱与全国性赛事结果等全民性热点同样通过。
- **三类强剔除**：成就宣传与态势综述（稳中向好 / 同比增长 / 再创新高等）、远期规划与未落地事项、与普通人无关的机构动态。剔除看稿件性质不看发布主体；政府发布的油价调整、气象预警、医保目录、社保办理、供暖退费等即时可行动民生信息一律保留。
- **判定式**：`reject_mass = ACHIEVEMENT_STRONG OR FAR_FUTURE OR UNRELATED`；`keep_mass = MASS_TOPIC_HIT OR NATIONAL_HOT`；reject 优先，命中即剔，未命中再看 keep。
- **国际动态仅三类重大突发**：战争与武装冲突、灾害与公共卫生、突发事故与重大安全事件。重大突破、选举换政、国际形势、中性国际资讯一律剔除并逐条留痕；直接波及境内普通人切身利益的按民生条目保留并标注依据。
- **编排**：表 R 由五组扩为八组（天气与出行 / 物价与消费 / 房价与居住 / 工作与收入与社保 / 医药与医保 / 产业与就业 / 社会议题 / 公共服务）。
- **交付契约不变**：12 列、五工作表、附录 1–18、来源列 `渠道 · 渠道`、议题簇去重、评分数值不被编排改动。

## 边界

1. 无 `SERPER_API_KEY` / `TAVILY_API_KEY` 时自动批次仍会标 `degraded`，产物是采集子集，不是全渠道全量。
2. 词组表按可核对词组实现，真实批次里新出现的表述可继续补进 `TABLE_MASS_TOPIC` / `TABLE_G_IMPORTANT`；模型语义层（若启用）只做已采片段内的判定，不新增事实。
3. 定时任务产物只推送到聊天窗口供下载，不写入 `get-news` 仓库；仓库侧 `data.xlsx` 由 Actions 链路生成。
4. 定时任务配置更新不等于确认调度执行，执行回执需在平台侧查看。
5. **唯一未改的一处**：定时任务到点执行说明里，第六节附录清单仍写「附录 1–17」，因为它那条会话内手工批次把逐条时间留痕单列、未编为第 18 号；口径条款（正面清单 / 三类强剔除 / 国际仅三类重大突发 / 表 R 八组 / 12 列 / 来源契约）已与规范一致。要连编号也对齐，需整体重写该指令，一句话即可办。
