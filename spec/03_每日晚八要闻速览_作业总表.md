# 每日晚八要闻速览 · 采集与评级作业总表

> **用途**：每晚 20:00 定时任务的作业依据。执行方按本表完成「信源采集 → 准入与评级 → 编排 → 产出 Excel → 推送」，其他执行方按同一口径可复现。
> **配套规范**：《每日要闻筛选评级SKILL.md》（评级与展示字段的唯一依据）、《每日要闻速览 · GitHub Pages 自动出表部署手册》（GitHub Actions 自动出表链路）、`每日要闻速览_产出模板.xlsx`（12 列空表骨架）。
> **三处口径一致**：在线本表、定时任务到点执行说明、部署包内规则引擎；三者均以《每日要闻筛选评级SKILL.md》为准。

---

## 0. 一句话作业流

**采集窗口 `(前一日 20:00, 当日 20:00]`（左开右闭）** → 按第 2 节信源清单**覆盖 8 个上位大类逐组采集** → 按第 3 节完成大众贴近度准入、国际仅重大突发限定、低价值过滤、打分、同事件聚类、议题簇去重、编排 → 按第 4 节产出五工作表 Excel → 推送本地文件。

**零缺口规则**：任意时刻发布的内容恰好被采集一次。前一日 20:00 整归上一批，当日 20:00 整归本批，两批不重叠、不重复采集。越接近 20:00 的突发越可能落入下一批；本批对采集截止后的事件不做推测补写，缺口由下一批从左端接续，不回溯、不重复补采。昨夜 20:00–24:00 的内容须采入，摘要写具体日期，「今天 / 昨日 / 今晨」等相对时间词一律改写成具体日期。

**最长 24 小时时效代价**：须在「口径与稿外信息」显式声明当批实际检索截止时间，不宣称是当日新消息全集、不宣称覆盖全天。

### 2.17 采集规则

1. **窗口**：`(前一日 20:00, 当日 20:00]`，左开右闭；超左 / 超右边界条目逐条写明时间证据，发布时点未取得标「时点推定」，不补造具体时刻。
2. **8 个上位大类逐组采集**：民生服务 / 财经市场 / 科技与产业 / 文娱与热榜 / 重要赛事 / 重大突发与司法 / 国际动态 / 社会治理与养老。**准入只在采集后执行**：禁止在采集阶段按题材或大类框定检索范围，禁止因用户口径跳过大类，禁止把检索词框死在民生刚需里。科技突破、平台功能变更、影片定档、赛果都正常进打分。某大类准入后 0 条须逐渠道申报「已触达但按某规则剔除 / 本轮未触达」，不得静默不采、不得编造凑数。
3. **★ 级必采，☆ 级按窗口热度筛，✗ 级仅作热度参考**（社交平台中 D01 / W01 / X02 例外，按 ★ 采集）。央媒 / 部委官网优先，媒体稿仅作补充；同事件多源取最权威原文。
4. **精选**：科技媒体取重大发布 / 首飞 / 首发，不采产品测评；财经媒体取数据 / 政策，不采个股 / 行情；赛事取赛果与定档，不采赛前预测。
5. **不采**：养生科普、纯地方琐事、站点首页与栏目入口、汇编早报目录项、结构化行情 / 比分表、无可点开独立原文的聚合词表。
6. **独立原文准入**：只收专门报道该事件、URL 指向该具体文章的独立文章。节目单、首页栏目、目录线索、站点首页 URL 一律剔除并逐条留痕。
7. **多事件拼盘稿拆分优先**：首段列举导语或「同榜还有… / 另有…」的罗列尾巴裁掉，主体事件必留，尾巴里每个词条拆成独立候选行并逐条回查独立原文；未取得原文的进附录 15「线索待原文」留痕，不静默消失；纯汇编母行剔母行但把它列出的词条全拆出来；叙述性尾巴（援引 / 报道称 / 维持在 / 同比等）不切成假词条；裁剪回退到上一个完整句末，不留半句。
8. **渠道覆盖表**逐渠道申报「已触达 / 未触达 / 按准入剔除」及条数；采集源分类提示只作词表无命中时的兜底，不得整批预设为某一大类。

## 3. 评级与准入口径

完整规则、大众贴近度词组表、公式与质检清单见《每日要闻筛选评级SKILL.md》，本节只列执行时必须落地的判定顺序与数值，便于在线核对。

### 3.1 三条铁律

1. **先判断「跟谁有关」，再判断「有多重要」**：一条影响上亿人下周买票的新闻，优先级高于措辞宏大但落地在 2030 年的规划。
2. **事实强度优先于流量奖励**：查不到原文就没有摘要，绝不靠常识脑补数字、比分、金额、结论。
3. **评分层、准入层、编排层三者分离**：准入 / 条数口径单独记录、不写进公式；编排层只改展示序。三者都不允许手工挪动某条的评分数值。

### 3.2 准入顺序与判定式

执行顺序：**大类级准入 → 大众贴近度准入 → 国际动态仅重大突发限定 → 低价值过滤 F1–F4 → 打分**。准入层只决定「收不收」，不进六维价值分、不改等级、不改位次，也不引用分类标签或信息功能档位。被剔条目逐条留痕、不删不改、不参与 `gin` / `Final_adj` / 截断 / 覆盖保底，`must_include` 同步移出。

- **大类级准入**：`EXCLUDED_GROUPS` 整类剔除；`GATED_GROUPS` 仅留命中「特别重要」可核对词组者（涉台 / 中国使馆 / 中国领空领海等，禁用裸「主权」「领土」）。
- **大众贴近度准入**（默认 `strict`，可切 `moderate` / `off`）：目标读者是普通大众，只收大多数人会关注、与日常生活和切身利益贴近的资讯；判定只看稿件性质，不看发布主体。
  - **正面清单 MASS_TOPIC**（词组表可核对、禁用裸词）：衣食住行与物价消费；工作与就业（裁员 / 欠薪 / 招聘 / 工时 / 劳动争议）；医保与社保（药品目录 / 报销比例 / 养老金 / 公积金 / 异地结算）；工厂与制造业；制药业与医药（药价 / 集采 / 新药获批 / 短缺药）；AI 发展（产品发布 / 产业落地 / 监管与就业影响）；新能源（车 / 电价 / 储能 / 充电）；地方政府负债与化债；房地产（房价 / 房贷 / 烂尾 / 保交楼 / 交房 / 租房）；企业经营恶化（倒闭 / 资不抵债 / 破产重整 / 退市 / 大面积关店）；社会议题（教育 / 医疗 / 养老 / 交通出行 / 环境 / 公共安全 / 消费维权 / 食品安全）。
  - **全民性热点 NATIONAL_HOT** 同样通过：重大天气与权威预警、全国性公共安全事件、现象级文娱与全国性赛事结果、涉及大范围人群的价格或政策变动；小众粉丝向、行业内部、无公共性的花边不通过。
  - **三类强剔除**（命中任一即终止、逐条留痕）：① `ACHIEVEMENT_STRONG` 成就宣传与态势综述——「稳中向好」「同比增长」「再创新高」「成效显著」「持续向好」等表述主导、无具体受影响对象与可行动项，政府 / 企业 / 媒体发布的同类稿一体适用；② `FAR_FUTURE` 远期规划与未落地——拟建、规划中、征求意见稿、框架协议、意向签约、试点意向、多年后目标、趋势预测、展望、前瞻，含「已生效 / 已开工投产 / 即时可办理 / 已公布具体执行日期」字段的不剔；③ `UNRELATED` 与普通人无关的机构动态——会见出席、会务筹备与预热、人事任免、外事礼宾、机构内部评优、行业年会、纯政策解读、无落地动作的部委通报。
  - **判据澄清**：机构名（国务院 / 发改委 / 外交部等）不得单独当删除开关；政府机构发布的即时可行动民生信息（油价调整、气象预警、医保目录、社保办理、供暖退费、疫苗、限行、放假安排、退费）一律保留，归入正面清单。所用档位、逐条命中词组、reject / keep 分支、命中总数、误伤数与逐条恢复开关写入口径说明与附录 1；被剔条目不参与 `gin` / `Final_adj` / 覆盖保底，`must_include` 同步移出。

```
reject_mass = ACHIEVEMENT_STRONG OR FAR_FUTURE OR UNRELATED
keep_mass = MASS_TOPIC_HIT OR NATIONAL_HOT
```

判定顺序：先算 `reject_mass`，命中即剔；未命中再看 `keep_mass`，命中即通过；两者皆未命中则剔。判据澄清：剔除看稿件性质，不看发布主体；机构名（国务院 / 发改委 / 外交部等）不得单独当删除开关，部委发布的油价、预警、疫苗、医保目录、社保办理、供暖退费、限行、放假安排等即时可行动民生信息一律保留并归入正面清单。所用档位、逐条命中词组、reject / keep 分支、命中总数、误伤数与逐条恢复开关写入口径说明与附录 1。

### 3.3 国际动态仅重大突发

国际动态只保留**三类重大突发事件**并标 `intl_important`：战争与武装冲突 / 灾害与公共卫生 / 突发事故与重大安全事件。全部由可核对词组表判定（沿用表 G-重要中这三类词组），禁用「重大 / 重要 / 影响大」主观词，禁止编辑逐条挑。「重大突破 / 选举换政 / 国际形势」、表 G-中性（自贸区 / 议定书 / 国际标准 / 汇率 / 全球机构等）、表 G⁻ 低重要度、其余中性国际资讯一律剔除并逐条留痕。

| 状态 | 判定 | 处理 |
|---|---|---|
| ① | 无 `INTL_GEO_SIGNAL` 境外主体信号且非国际动态 | 不进本层（词表误分类） |
| ② | 命中三类重大突发 | 保留 + 标 `intl_important` + 三类重大突发标签 |
| ③ | 重大突破 / 选举换政 / 国际形势 / 表 G-中性（自贸区 / 议定书 / 国际标准 / 汇率 / 全球机构等） | 剔除并逐条留痕 |
| ④ | 命中表 G⁻ 低重要度（非法移民 / 合作年 / 会务花絮 / 会议预热等） | 剔除 |
| ⑤ | 其余中性国际资讯 | 剔除并逐条留痕 |

唯一例外：事件直接波及境内普通人切身利益（跨境航班大面积取消、进口药断供、境外重大灾害涉中国公民、跨境价格或供应突变）时，按民生条目保留并标注依据，不标 `intl_important`。命中明确境外国家 / 地区 / 组织名即优先归「国际动态」，分类只作元数据。附录 13 逐条列境外信号、重要标记、三类重大突发标签、判定依据与非重大突发剔除原因，并补记被前置规则剔掉的国际条目；口径正文写「国际动态仅重大突发」声明，报告保留 / 剔除 / 重要条数与三类逐类计数。某类 0 条或零国际条目须显式声明是采集数据缺口，不得用无该类条目的批次冒充口径已验证。

### 3.4 低价值过滤（评分前置，先剔后评）

执行顺序 F1 → F2 → F3 → F4，命中即过滤，不进打分、不进 `gin`、不出现在主表，仅在争议时列入附录 2。

| 规则 | 过滤对象 | 说明 |
|---|---|---|
| F1 | 纯规划 / 条例 / 征求意见 | 无即时强制力、不含执行动作与处罚 / 生效 / 施行表述；国家级重大立法例外 |
| F2 | 单市 / 区县非紧急 | 单一城市 / 区县名 + 试行 / 新增 / 可办 / 上线，且不含预警 / 伤亡 / 司法 |
| F3 | 纯地方政务 / 局部节点 | 某省 / 某市 + 治理 / 整治 / 推进 / 建设局部节点，且 C 维度为本地性；重要国际事故与司法 / 维权主体词豁免 |
| F4 | 软文 / 特写 / 成就抒情 | 命中表 H 词组 **AND** 未命中任何正向信息功能档位 **AND** 无带单位实质数字，三条件缺一不可 |

### 3.5 打分与等级

- **信息功能档位 I/C 单条取最高一档、不叠加**：`I = min(20, I_base + I_func)`，`I_base=5`（含明确受影响对象）否则 3；`C = min(10, 1 + C_func)`；I 档位 +9 / +7 / +5 / +5 / +5 / +4 / +4 / +1 / 0（重大伤亡 / 权威预警 / 终局性新规 / 国家级响应 / 重大司法终局 / 重大数据 / 科技工程突破 / 消费警示 / 便民提示），C 档位 +3 / +2 / +1（全国性 / 区域性 / 本地性）。逐条打印命中词组复核表，禁用泛词裸词，不按类目名称加分。
- **T**：当日清单内「发布时间距采集窗口中点小时差」样本自适应百分位（最近→25，最旧→0），禁止 `has_update` 系数；`pub` 缺失取批内已知时刻年龄中位数。
- **V**：`(0.24T + 0.18I + 0.14A + 0.10C + 0.06M + 0.10V核实) / 0.82 × 5`；质量惩罚（旧闻 −8 / 标题正文失配 −5 / 仅自媒体 −5 / 无新事实 −4 / 无更新时间 −3）与三态核实（部分核实封顶 C、未核实不得进 A 级）。
- **H 通道**：>70% 条目无平台后台阅读 / 播放 / 讨论数时，`P` / `H` 一律置 NULL，`Final = V / 82.32 × 100`，口径声明「H 通道关闭、Final 仅反映价值分 V」，并说明娱乐 / 赛事系统性偏低属数据缺口而非重要性判断；严禁构造虚假 H、不补零、不二次归一化、不把多渠道说成实测热度。
- **等级按原始 Final 机械映射**：S≥85 / A 70–84.9 / B 55–69.9 / C 40–54.9 / D<40；S 可为空、不凑档位；D 如实标注、不作准入剔除。
- **展示分**：`gin` 按上位大类内 Final 降序、按事件主键去重计数；`cap` 由信息功能档位触发 4 / 3 / 2；`λ=6`，`Final_adj = Final − 6 × min(gin−1, cap)`；展示分可为负、不加下限、不手工挪位次。用户未指定条数则不设上限；指定时按保护截断（protected = 命中重大伤亡 / 终局性新规 / 权威预警 / 重大司法终局 OR 原始 Final≥70，加大类覆盖保底）并做反事实验证。

### 3.6 同事件聚类、议题簇去重、多渠道与编排

- 采集层只去「标题 + 渠道 + URL 全同」的完全重复，同事件不同渠道一律保留；准入后按 2-gram Jaccard / LCS / 共享数字锚点 / 事件词组保守聚类，统一事件主键，原始 eid 留 `eid_raw` 逐对留痕。数字锚点须带单位或小数且标题共享中文实词。
- `cross_score = min(12, (独立信源渠道数 − 1) × 3)`，只进编排分 U，不进 H / V / Final；全单源批次如实写 0。主表与「排名最靠前的10条」按事件主键去重，完全重复行 0；「窗口内全部数据」为筛选前候选池，不去重不合并。代表条「来源」统一写 `渠道 · 渠道`，只列可核对的平台 / 媒体名，被合并渠道记录全进附录 12b。
- **编排分 U**（只决定展示序，不改 `Final` / `Final_adj` / 等级 / `gin` / `cap` / `V` / `I` / `C` 任何数值）：

```
daily_score = min(12, 4×命中的不同日常组数 + min(4, 命中词组总数))
              表 R 八组：天气与出行 / 物价与消费 / 房价与居住 / 工作与收入与社保 / 医药与医保 / 产业与就业 / 社会议题 / 公共服务
U = daily_score + cross_score
  + 8 × clip(Final_adj / 本批最大值, 0, 1)
  + 重要国际动态加权 6 + 可配标签加权
```

天气不硬置顶，作为表 R 高相关组之一自然靠前。`orchestrate=false` 回纯 `Final_adj` 降序。

### 3.6.1 议题簇去重（同一议题的不同侧面）

事件层与议题层严格分离，两者不可混用。

- **事件层 eid**：同一件事的不同渠道稿，按共享数字锚点 / 事件词组 / 标题字面重合聚类；主表与前 10 各留 1 行，候选池不参与、各渠道稿全部保留，渠道明细进附录 12b；**计入 cross_score**，独立信源是可数序次信号。
- **议题层 sid**：同一议题下不同侧面（如美伊冲突的袭击、使馆警报、油轮触雷、无人机打击）；三表每簇各留 1 条代表条，其余完整内容进附录 17；**不计入 cross_score**，不得把多家媒体虚增成同一事件的多渠道热度。

议题词组表可配置，每组含 `name / subjects / actions`，默认内置「美伊冲突与海湾局势」「俄乌局势」两组，可用 `story_groups` 增删。判定条件：主体词必须命中标题（汇总稿与陈年存档稿的摘要常夹带各种国名，允许摘要命中主体会把不相干稿件拉进簇），动作词可来自标题或摘要；至少命中 1 个主体词，且主体与动作合计命中 ≥2 个不同词，才归入该议题。

代表条优先取簇内基准分 `Final_adj` 最高者（该议题最突出的一条），其次按标题命中主体词数；不按摘要长度选——聚合稿往往摘要最长。代表条「内容摘要」保持原文，不把被合并条内容塞进该列；展示序由编排层在去重后重算。

`story_max_keep` 默认 1，可设为 2 以保留两条不同侧面；`story_dedup=false` 关闭整层。附录 17 逐条列议题名、代表条、被合并条标题与来源、摘要首段、命中主体与动作词组，完整内容不删除、不静默消失。口径表新增「议题簇去重」项，报告合并条数与议题簇数；质检须确认议题层未虚增 `cross_score`、来源列统一为 `渠道 · 渠道` 且无编号 / 竖线 / 链接 / 占位 / 括注 / 重复计数标记。

### 3.7 头部三席、覆盖保底与相邻打散

- **头部三席独立判定**：资格池 = `cross_score>0` 且 `daily_score>0`（多渠道 + 日常相关，池不足 3 条才放宽并声明）；`head_score = 1.8×daily_score + 1.5×cross_score + 6×clip(Final_adj/本批最大值,0,1)`，头部不给重要国际动态额外加权；逐槽在「上位大类 ≠ 上一条」候选里取最高。头部不参与覆盖保底换出，头部末条大类与标签传给前窗打散；第 4 位起沿用编排。`head_window=0` 关闭。
- **前窗 10 条**：`front_cap` 必须扣减头部占席；同一上位大类最多 3 条（重要国际动态名额 4），前窗内同一三类重大突发标签最多 1 条；未被覆盖但有准入条目的大类做覆盖保底换入并逐条留痕；容量不足时上限放宽并如实声明。覆盖统计必须含头部三席。
- **相邻同类打散**：在 U 降序序列上贪心交错，**前窗相邻同大类必须为 0**；主键上位大类、次级分类标签（国际动态用三类重大突发标签，其余用细标签，U 差 ≤1.0 时优先错开）；front→tail 边界传递大类与标签；容量不足被迫连续同类须逐条列位置、大类、标签与原因。`interleave=false` 关闭。
- 附录 11 编排留痕、附录 16 头部留痕、附录 14 打散对照逐条列「U 降序位 → 展示序」、日常组、独立渠道数、`cross_score`、U、`Final_adj` 与动作。展示序与 `Final_adj` 严格降序不一致须如实标注，不得包装成公式结果。

**主表与「排名最靠前的10条」按事件主键去重，完全重复行必须为 0**；「窗口内全部数据」是筛选前的采集候选池，只去采集层「标题 + 渠道 + URL 全同」的完全重复，不按事件主键去重、不做事件层或议题层合并、不施加贴近度筛选与三类强剔除，评级列一律置「—」、展示序为采集序 1–N。关系为 **窗口内全部数据（候选池）⊇ 主表 ⊇ 前 10**；候选池条数不设限、不截断、不删被筛掉或被合并的条目。被合并的渠道记录不删除，逐条列入附录 12b。同一议题的不同侧面另按 §3.6.1 议题簇去重，**主表与前 10 每簇各保留 1 条代表条**（候选池不参与、各侧面全部保留），其余完整内容进附录 17；删行后「排名最靠前的10条」须补足 10 行且与主表前 10 行逐格一致，窗口内全部数据 ⊇ 主表 ⊇ 前 10 仍成立。

### 4.3 内容摘要规范

- **底稿是采集到的原文摘要全文**，保留原文事实骨架、句式与数字，不是另行提炼的独立句子。
- **仅当原摘要 >240 字才精简**：按整句 / 整分句累加，绝不切半句；删冗长枚举、次要背景与重复，保留优先级「数字与单位 > 时间地点 > 可行动项 > 口径限定 > 背景成因」；被删背景不补写、**不改写任何数字**；≤240 字的原摘要只做语句顺接与分段，不强行压缩。整格 ≤240 字。
- 按语义分 **2–3 个自然段**（事实与背景 / 影响与可行动项 / 口径限定·快照·风险提示），段间用 LF 换行（禁 CRLF），**每段开头缩进 2 个全角空格**（U+3000×2）；只放正文，无标签、无关键词、无重点句、无「详情以原文为准」类占位句。
- 原文摘要缺失 / 过短时用标题补成完整陈述，不编造数字与细节，`abstract_source` 逐条留痕；同事件多渠道复用同一摘要。
- 标准 CSV / JSON 解析器会把含 LF 的字段用双引号包裹并完整读回，**禁止按行 split 整个文件**。

示例：

```
　　中央气象台11月14日18时继续发布大雾橙色预警：预计14日夜间至15日上午，北京大部、天津、河北大部、山东中北部和西部、河南大部等地部分地区有大雾，局地有能见度低于50米的特强浓雾。
　　15日白天起受冷空气影响，雾和霾自北向南逐渐减弱或消散，驾驶需减速慢行。
```
